# Authorship

The four featured automation workflows were designed and built by Paul Hopgood from scratch. The local-model evaluation methodology, scenarios, scoring rules, harnesses and acceptance decision were also Paul's work.

AI coding tools were used as a development aid for selected JavaScript and Python. Their output was reviewed, tested and adapted before use. The system design, workflow structure, integrations, data mapping, evaluation design, testing and operational decisions were Paul's work.

Experiments that began from public templates are not included as original portfolio case studies. If a template-derived example is added later, its source and the extent of the changes will be stated clearly in that case study.
